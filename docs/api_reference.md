# API Reference

Добро пожаловать в API-документацию библиотеки `pysatl_tsp`.

::: pysatl_tsp
    options:
      show_submodules: true # Показывает подмодули (файлы .py) в пакете
      show_category_heading: true # Группирует объекты по категориям (модули, классы, функции)
      show_root_toc_entry: false # Не отображать сам корневой пакет в содержании, если он не нужен там
      members: true # Важно: отображает всех членов пакета и его подпакетов
